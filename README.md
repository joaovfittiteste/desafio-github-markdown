Desafio de teste para comandos de Git e Markdown
- *Objetivos:*
  - Realizar alterações e commits
  - Abrir Issues
  - Realizar Pull Requests

1. Criar uma conta no Github
2. Criar um novo repositório
3. Adicionar um Readme
4. Adicionar um colaborador
5. Realizar commits, issues e pull requests
6. Editar o Readme utilizando Markdown
